🛡️ Gatekeep

Wallet & transaction guard agent — screens approvals, transactions and tokens before you sign, and returns a deterministic, signed verdict.

What it does

Paste a wallet address, a pending transaction, or a token address. Gatekeep checks it against live on-chain data (public RPC + DexScreener) and answers one question: is it safe to sign?

Checks: unlimited-approval decoding, spender reputation (known protocol / unknown contract / plain wallet / fresh address), token contract + owner privileges, DEX liquidity / age / buy-sell balance, and your wallet's open unlimited approvals. Every verdict is deterministic, reproducible from public chain data at a stated block height, and signed with the agent's per-deployment ed25519 key. Nothing here moves funds — all reads are eth_call / public GETs.

Verdict

What Gatekeep does NOT do

No contract-source verification, no LP lock/burn or holder-concentration data, no sell simulation (no keyless source for those) — a low score means "no red flags found in the checks above", not "this token is safe". "Unknown" checks never add risk points. Full limits in the README.
